# Mobile Robot Localization using Particle Filters

## Description
A probabilistic robot localization system that uses particle filters, sensor observations, and motion models to estimate a robot’s position in a 2D environment.

## Features
- 2D Grid Environment
- Particle Filter Localization
- Landmark-Based Sensing
- Heatmap Visualization
- Probabilistic State Estimation
- Animated Robot Simulation

## Technologies Used
- Python
- NumPy
- Matplotlib

## How to Run

1. Install required libraries:

pip install numpy matplotlib

2. Run the Python file:

python filename.py

## Project Concepts
- Mobile Robot Localization
- Particle Filters
- Bayesian Estimation
- Motion Models
- Observation Models

## Output
The simulation displays:
- Actual robot position
- Estimated robot position
- Particle distribution
- Localization heatmap
